# Задача 24048 (ЕГЭ №14)

( В. Лашин )  Операнды равенства записаны в системе счисления с некоторым основанием p 
 \(KOT_p + GOLODNI_p = MEEOW_p * 100_p - 20194023088_{10}\)​ 
 Определите наименьшее возможное основание системы счисления, при котором данное равенство будет выполняться. Для найденной системы счисления p вычислите и укажите в ответ значение арифметического выражения \(PURR_p\) в десятичной системе счисления. Основание системы счисления указывать не нужно.
