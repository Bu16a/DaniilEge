# Задача 24534 (ЕГЭ №14)

(М. Рубцова)   Значение арифметического выражения 7 270  + 7 170  + 7 70  – х, где х – целое положительное число, не превышающее 11500, записали в 7-ричной системе счисления. Определите наибольшее значение х, при котором количество нулей в 7-ричной записи числа, являющегося значением данного арифметического выражения, максимально.  
 В ответе запишите число в десятичной системе счисления.
