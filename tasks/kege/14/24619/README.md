# Задача 24619 (ЕГЭ №14)

 \(SLADOST_{36} + GADOST_{10x} = HALLOWEEN_{50 - x} - 166729861760449_{10}\)

Для найденного x найдите значение \(GADOST_{x13} \) и укажите его в ответе в десятичной системе счисления . Основание системы счисления в ответе указывать не нужно.
