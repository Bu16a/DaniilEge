# Задача 27294 (ЕГЭ №14)

Значение арифметического выражения 39 483  + 39 235  – х, где х – натуральное число, не превышающее 9430, записали в 39-ричной системе счисления. Определите максимальное возможное количество нулей в 39-ричной записи числа, являющегося значением данного арифметического выражения. В ответе запишите только целое число.
