# Задача 27296 (ЕГЭ №14)

Операнды арифметического выражения записаны в системе счисления с основанием 27. 
 ABxCD 27  + APxDK 27 
 В записи чисел переменной x обозначена неизвестная цифра из алфавита 27-ричной системы счисления. Определите наименьшее значение x, при котором значение данного арифметического выражения кратно 26. Для найденного x вычислите частное от деления значения арифметического выражения на 13 и укажите его в ответе в десятичной системе счисления. Основание системы счисления указывать не нужно.
