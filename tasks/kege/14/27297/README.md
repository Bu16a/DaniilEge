# Задача 27297 (ЕГЭ №14)

Операнды арифметического выражения записаны в системе счисления с основанием 19. 
 2ExG8 19  + 6FxBG 19 
 В записи чисел переменной x обозначена неизвестная цифра из алфавита 19-ричной системы счисления. Определите наибольшее значение x, при котором значение данного арифметического выражения кратно 18. Для найденного x вычислите частное от деления значения арифметического выражения на 9 и укажите его в ответе в десятичной системе счисления. Основание системы счисления указывать не нужно.
