# Задача 27626 (ЕГЭ №14)

Значение арифметического выражения \( 6^{2030} + 6^{100} - х \), где х - целое положительное число, не превышающее 2030, записали в 6-ричной системе счисления. Определите наименьшее количество нулей, которое может содержаться в этой записи. 
 В ответе запишите число в десятичной системе счисления.
