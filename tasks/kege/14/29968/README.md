# Задача 29968 (ЕГЭ №14)

Значение арифметического выражения \( 9 \cdot 11^{210} + 8 \cdot 11^{150} - x \), где х - целое положительное число, не превышающее 3000, записали в 11-ричной системе счисления. Определите наибольшее значение х, при котором в 11-ричной записи числа, являющегося значением данного арифметического выражения, содержится ровно 60 нулей. 
 В ответе запишите число в десятичной системе счисления.
