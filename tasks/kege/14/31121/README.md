# Задача 31121 (ЕГЭ №14)

Значение арифметического выражения \( 5^{150} + 5^{100} - х \), где х - целое положительное число, не превышающее 2030, записали в 5-ричной системе счисления. Определите наибольшее значение х, при котором количество нулей в 5-ричной записи значения арифметического выражения максимально. 
 В ответе запишите число в десятичной системе счисления.
