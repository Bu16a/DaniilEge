# Задача 31222 (ЕГЭ №14)

Операнды арифметического выражения записаны в системе счисления с основанием 19. 
 \( 76x79645_{19} + 35x42_{19} + 332x6_{19} \) 
 В записи чисел переменной х обозначена неизвестная цифра из алфавита 19-ричной системы счисления. Определите наибольшее значение х, при котором значение данного арифметического выражения кратно 18. Для найденного вычислите частное от деления значения арифметического выражения на 18 и укажите его в ответе в десятичной системе счисления. Основание системы счисления указывать не нужно.
