# Задача 31360 (ЕГЭ №14)

Операнды арифметического выражения записаны в системе счисления с основанием 22. 
 \( 27x98966_{22} + 26x33_{22} + 522x5_{22} \) 
 В записи чисел переменной х обозначена неизвестная цифра из алфавита 22-ричной системы счисления. Определите наибольшее значение х, при котором значение данного арифметического выражения кратно 21. Для найденного х вычислите частное от деления значения арифметического выражения на 21 и укажите его в ответе в десятичной системе счисления. Основание системы счисления указывать не нужно.
