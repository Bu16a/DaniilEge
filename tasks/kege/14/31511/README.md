# Задача 31511 (ЕГЭ №14)

Операнды арифметического выражения записаны в системе счисления с основанием 22. 
 \( 27x98876_{22} + 26x51_{22} + 711x5_{22} \) 
 В записи чисел переменной x обозначена неизвестная цифра из алфавита 22-ричной системы счисления. Определите наименьшее значение x, при котором значение данного арифметического выражения кратно 21. Для найденного x вычислите частное от деления значения арифметического выражения на 21 и укажите его в ответе в десятичной системе счисления. 
 Основание системы счисления указывать не нужно
