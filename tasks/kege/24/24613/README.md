# Задача 24613 (ЕГЭ №24)

( В. Лашин )  Текстовый файл состоит из десятичных цифр и заглавных букв латинского алфавита. Определите, сколько в этом файле подпоследовательностей подряд идущих символов, в которых каждое из слов: 'HALLOWEEN', 'TRICK' и 'TREAT' встречается ровно по 5 раз. 

 В ответе запишите число — количество подходящих подпоследовательностей. 

 Для выполнения этого задания необходимо написать программу.
