# Задача 26491 (ЕГЭ №24)

( Иглин К. )  Текстовый файл состоит из десятичных цифр, знаков «+» и «*» (сложения и умножения). Определите максимальное количество символов в непрерывной последовательности, являющейся корректным арифметическим выражением с целыми положительными числами (без знака), значение которого равно чётному числу. В этом выражении никакие два знака арифметических операций не стоят рядом, порядок действий определяется по правилам математики. В записи чисел отсутствуют незначащие (ведущие) нули. 
 В ответе укажите количество символов.
