# Задача 31230 (ЕГЭ №24)

Текстовый файл состоит из заглавных букв латинского алфавита А, В, С, D, Е и F. Определите в прилагаемом файле минимальное количество идущих подряд символов, среди которых тройка букв АВС (в указанном порядке) встречается ровно 110 раз, при этом искомая последовательность заканчивается буквой С. В ответе запишите число - количество символов в найденной последовательности. 
 Для выполнения этого задания следует написать программу.
