# Задача 20954 (ЕГЭ №8)

(М. Попков)  Все шестибуквенные слова, в составе которых могут быть только русские буквы М, А, К, С, записаны в алфавитном порядке и пронумерованы начиная с 1. 
 Вот начало списка: 
 1. АААААА 
 2. АААААК 
 3. АААААМ 
 4. АААААС 
 5. ААААКА 
 … 
 Под каким номером в списке идёт последнее слово, которое не содержит ни одной буквы C, ни одной буквы М и не содержит букв К стоящих рядом?
