# Задача 24455 (ЕГЭ №8)

 1. АААААА 
 2. АААААВ 
 3. АААААИ 
 4. АААААК 
 5. АААААЛ 
 6. АААААО 
 7. АААААР 
 …… 
 Найдите сумму номеров слов ВИКТОР и КИРИЛЛ . 
 Примечание.  Слово – последовательность идущих подряд букв, не обязательно осмысленная.
