# Задача 24533 (ЕГЭ №8)

(М. Рубцова)   Все семибуквенные слова, составленные из букв Н, Е, А, Т, О, К записаны в алфавитном порядке и пронумерованы. 
 Вот начало списка: 
 1. ААААААА 
 2. ААААААЕ 
 3. ААААААК 
 4. ААААААН 
 5. ААААААО 
 6. ААААААТ 
 …… 
 Определите, под каким номером в этом списке стоит последнее слово с нечётным номером, которое может быть составлено путём перестановки букв из набора Е, К, К, Н, О, О,  Т,  . 
 Примечание.  Слово – последовательность идущих подряд букв, не обязательно осмысленная.
