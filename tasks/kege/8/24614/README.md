# Задача 24614 (ЕГЭ №8)

( Лысенков О. )  Токсичный информатик составляет новые предложения из 7 символов взятых из предложения "КОНФЕТЫ ИЛИ ЖИЗНЬ", используя каждый символ количество раз, не превышающее его число вхождений в изначальное предложение. Ему стало интересно, сколько среди данных предложений будет страшных ошибок. Страшной ошибкой он считает два пробела идущих подряд.
