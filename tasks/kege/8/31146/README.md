# Задача 31146 (ЕГЭ №8)

Все шестибуквенные слова, составленные из букв П, Л, А, Н, Е. Р, записаны в алфавитном порядке и пронумерованы. 
 Вот начало списка: 
 1. AAAAAA 
 2. AAAAAE 
 3. АААААЛ 
 4. АААААН 
 5. АААААП 
 6. AAAAAP 
 Определите, под каким номером в этом списке стоит последнее слово с нечётным номером, в записи которого не содержится ни одной из букв П или Р и при этом имеется ровно две буквы А и ровно одна буква Н. 
 Примечание.  Слово - последовательность идущих подряд букв, не обязательно осмысленная.
